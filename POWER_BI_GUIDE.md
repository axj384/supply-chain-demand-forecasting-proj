# Power BI build guide
1. Import `data/sample_data.csv` using Get Data > Text/CSV.
2. Confirm dates and numeric types in Power Query.
3. Add KPI cards, line charts, and categorical bar charts using the measures described in README.md.
4. Add slicers for relevant date and category fields.
5. Publish dashboard screenshots to `figures/` and save the PBIX locally.

Note: Power BI Desktop is Windows-focused; Mac users can use a Windows environment for PBIX authoring. Excel and Python outputs work on Mac.
